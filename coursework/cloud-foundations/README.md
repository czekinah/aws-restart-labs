## What this track covers

- **Sandbox discipline.** Every lab runs in a disposable account on a timer. Resources left behind cost money and clutter the next session, so the cleanup step is part of the lab, not an afterthought.
- **EC2 as the default unit.** Launch, connect, terminate. Instance type, key pair, security group and subnet are the four choices that decide whether the instance is reachable and what it costs.

> [!TIP]
> Region is the setting people get wrong first. Resources are regional, so an instance launched in the wrong one is invisible from the console you are looking at.
