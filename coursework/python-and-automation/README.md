## What this track covers

- **The case for automating.** A task done once by hand is fine. The same task done weekly by hand is a defect rate waiting to be measured.
- **Choosing a tool.** What it does, what it assumes about your environment, and what it costs to leave. The third question is the one that gets skipped.
- **Python as the glue.** Variables, flow control, functions, modules, and error handling that says what went wrong rather than stopping.
